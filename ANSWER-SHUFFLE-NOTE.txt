Answer Shuffle Update

Multiple-choice answer positions are now randomized in 14 labs.

Design choice:
- The order is randomized when the page loads.
- If a student selects a wrong answer and chooses Try Again, the same question keeps the same answer order. This avoids moving the choices while the student is using feedback to reconsider.
- Correctness and feedback are attached to the answer itself, not its screen position.
- The activity "Too Obvious, Too Wild, or Just Right?" remains intentionally ordered because the three choices form a meaningful conceptual scale rather than an arbitrary set of options.
