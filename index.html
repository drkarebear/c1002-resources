Choose a Skill

Literary analysis gets easier when you break it into four moves.

1

Notice

See what the text is doing.

  • Tell summary from analysis
  • Notice details and patterns
  • Ask useful questions
  • Zoom in on language
Choose a Notice activity
2

Interpret

Ask what the pattern might mean.

  • Move from observation to interpretation
  • Test whether a reading fits the evidence
  • Build thematic ideas
  • Analyze perspective
Choose an Interpret activity
3

Support

Use evidence and explain it.

  • Tell claims, evidence, and explanation apart
  • Integrate quotations
  • Explain how evidence supports a claim
Choose a Support activity
4

Develop

Build and complicate an argument.

  • Strengthen a thesis
  • Revise when evidence complicates a claim
  • Repair weak analysis
Choose a Develop activity
Not sure which one to choose? Start with Notice. The four moves build on one another, but you do not have to complete every activity.

Using These Labs

For Students

You can use these activities before, during, or after working on a literary analysis assignment.

  • Choose the move that matches where you feel stuck.
  • Read the feedback even when your first answer is correct.
  • Try again when an answer does not work.
  • Use the completion screen if your instructor asks for proof.
