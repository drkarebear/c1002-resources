For Instructors

Assign a specific literary-analysis lab, or let students choose one activity from Notice, Interpret, Support, or Develop. Each option below includes a public student link and Canvas-ready iframe code.

Two easy ways to assign these labs:

Choice assignment: send students to one of the four move pages and ask them to choose one activity.

Specific assignment: link or embed one individual lab.

Each lab is designed as low-stakes practice and ends with a mobile-friendly completion screen students can screenshot if you require proof of completion.

Using an Embed in Canvas

  1. Create or edit a Canvas Page.
  2. Switch the Rich Content Editor to the HTML Editor.
  3. Paste the iframe code from the activity you want to assign.
  4. Save the page and preview it in Student View.

Mobile note: A direct link is often the simplest option for students working on phones. If an embedded lab feels cramped in your Canvas course, use the public student link instead.
