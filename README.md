## Security and Privacy

The Learning Lab is intentionally static and data-minimizing. It does not use accounts, analytics, cookies, browser storage, databases, or network APIs for student activity data. Student choices and progress remain in the browser and are not submitted to the site.

Security hardening includes a site-wide no-referrer policy, a restrictive Content Security Policy appropriate for the static architecture, no-referrer Canvas embed snippets, defensive URL-parameter handling on the reflection page, and safer DOM construction for dynamic activity content.

Future changes should preserve these boundaries: do not place credentials in browser-delivered code; do not send student work or identifiers to URLs or third-party services; and avoid inserting user- or URL-derived text with `innerHTML`.
