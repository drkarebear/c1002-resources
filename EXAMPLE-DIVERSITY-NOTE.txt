C1002 Example Diversity Pass

This pass reduces cross-lab repetition of a few memorable examples
(the wild garden, Little Red Riding Hood / the wolf, the swallowed hallway,
and the locked window / line of light).

Public-domain source pools used for brief adapted plot situations:
- Grimm's Fairy Stories: Cinderella, Rumpelstiltskin, The Goose-Girl,
  The Six Swans, The Frog Prince. Project Gutenberg #11027.
- Andersen's Fairy Tales: The Emperor's New Clothes, The Snow Queen,
  The Fir Tree, The Little Match Girl, The Red Shoes. Project Gutenberg #1597.
- Joseph Jacobs, Indian Fairy Tales: The Tiger, the Brahman, and the Jackal;
  The Talkative Tortoise. Project Gutenberg #7128.

Design rule:
Repetition inside one lab can remain when students need to compare several
interpretations of the same evidence. The problem being reduced is repetition
of the same distinctive scenario across many separate labs.

Too Obvious / Too Wild / Just Right:
The item types are now shuffled within each round at page load.
The original obvious → right → wild sequence is explicitly excluded.

Second-pass balancing
The first replacement pass made The Emperor's New Clothes and The Fir Tree too
common. A second pass redistributed examples to Snow White, The Nightingale,
Hansel and Gretel, Rapunzel, Mother Holle, and an original micro-passage.
